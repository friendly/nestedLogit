# Effect Displays for Nested Logit Models

Computes effects (in the sense of the effects package—see, in
particular, [`Effect`](https://rdrr.io/pkg/effects/man/effect.html))—for
`"nestedLogit"` models, which then can be used with other functions in
the effects package, for example,
[`predictorEffects`](https://rdrr.io/pkg/effects/man/predictorEffects.html)
and to produce effect plots.

## Usage

``` r
# S3 method for class 'nestedLogit'
Effect(
  focal.predictors,
  mod,
  confidence.level = 0.95,
  fixed.predictors = NULL,
  ...
)
```

## Arguments

- focal.predictors:

  a character vector of the names of one or more of the predictors in
  the model, for which the effect display should be computed.

- mod:

  a `"nestedLogit"` model object.

- confidence.level:

  for point-wise confidence bands around the effects (the default is
  `0.95`).

- fixed.predictors:

  controls the values at which other predictors are fixed; see
  [`Effect`](https://rdrr.io/pkg/effects/man/effect.html) for details;
  if `NULL` (the default), numeric predictors are set to their means,
  factors to their distribution in the data.

- ...:

  optional arguments to be passed to the
  [`Effect`](https://rdrr.io/pkg/effects/man/effect.html) method for
  binary logit models (fit by the
  [`glm`](https://rdrr.io/r/stats/glm.html) function).

## Value

an object of class `"effpoly"` (see
[`Effect`](https://rdrr.io/pkg/effects/man/effect.html)).

## References

John Fox and Sanford Weisberg (2019). *An R Companion to Applied
Regression*, 3rd Edition. Sage, Thousand Oaks, CA.

John Fox, Sanford Weisberg (2018). Visualizing Fit and Lack of Fit in
Complex Regression Models with Predictor Effect Plots and Partial
Residuals. *Journal of Statistical Software*, 87(9), 1-27.

## See also

[`Effect`](https://rdrr.io/pkg/effects/man/effect.html),
[`plot.effpoly`](https://rdrr.io/pkg/effects/man/plot.effect.html),
[`predictorEffects`](https://rdrr.io/pkg/effects/man/predictorEffects.html)
